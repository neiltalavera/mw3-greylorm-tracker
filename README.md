# Red Worm USB Tracker

A small Windows guide and tracker for collecting the four Calibration Data USBs and locating the Greylorm (Red Worm) fight in **Call of Duty: Modern Warfare III Zombies**. It does not interact with or automate the game.

## Using the tracker

1. In Urzikstan, visit any of the four clue rooms: **C1** (Kotovo Blocks), **H2** (Orlov Military Base), **E8** (Urzikstan University), or **G7/G8** (Ah-Dahr Estates). The map on the wall shows that match's four UAV tower locations.
2. Open **Red Worm** in the app and choose the four matching clue photos for its four slots. Use **Show Map** to view the clue-room locations. The photo choices correspond to the tower spots; they are not the USBs themselves.
3. Press **Get Summary**. The summary shows the selected USB tower locations on the Urzikstan map. Select a **TARGET** button to open its closer view; a purple star marks the tower. Visit each marked UAV tower and interact with it to collect its Calibration Data USB.
4. At the end of the match, find the Red Worm arena: compare the four possible red skull markers on the map and choose the one with **two ammo caches close together**. Four refractors at that site take the USBs.
5. Watch the Aether Storm. USBs can be inserted only after the storm covers the refractors. Prefer an arena near the storm when it begins closing in: less travel during the limited storm window means more time to fight Greylorm and claim the reward.

The clue maps and tower spawns are match-specific. Collect all four USBs in the same match; they cannot be carried into another match. The tracker is a visual reference, so confirm locations and the storm in game.

## Download

Download `COD-Red-Worm-Tracker-win-x64.exe` from a [GitHub Release](../../releases). The release build is a self-contained, single-file Windows x64 executable; no separate .NET runtime installation is required.
